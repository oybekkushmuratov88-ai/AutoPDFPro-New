## O‘rnatish
1. AutoCAD va ZWCAD ni yoping.
2. `AutoPDFPro-3.0.1-Setup.exe` ni ishga tushiring → **Ha**. “Windows protected your PC” chiqsa: **More info → Run anyway**.
3. Tilni tanlang → topilgan dasturlar belgilangan bo‘ladi → **O‘rnatish**.
4. AutoCAD/ZWCAD da `AUTOPDF` → bir marta ro‘yxatdan o‘ting → administrator ruxsat bergach ishlaydi.

## Install
1. Close AutoCAD and ZWCAD.
2. Run `AutoPDFPro-3.0.1-Setup.exe` → **Yes**. If SmartScreen appears: **More info → Run anyway**.
3. Choose the language → the applications found on the PC are preselected → **Install**.
4. In AutoCAD/ZWCAD type `AUTOPDF` → register once → works after the administrator approves.

Built with `build/build.sh Release`. 3.0.0 was withdrawn: it pointed to the previous licence-server URL. Administrator setup: [server/licensing/README.md](../server/licensing/README.md).
